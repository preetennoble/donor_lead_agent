FLOW:
=====

1. User sends POST to /research/financial with company_name and website
2. App creates company record in MongoDB
3. research_company_with_financials() starts:
   - Search Screener for company link
   - Search for annual report PDF
   - Download and extract PDF text
   - Use Claude LLM to extract financial data
   - Check if meets prospect criteria
   - Save all data to MongoDB
   - Mark is_prospect: true/false

4. Frontend displays:
   - Turnover (FY25, FY24, FY23)
   - PBT (FY25, FY24, FY23)
   - Net Profit (FY25, FY24, FY23)
   - Net Worth (FY25, FY24, FY23)
   - Annual CSR Spend
   - Prospect Status (✅ YES / ❌ NO)
   - CSR Focus Areas
   - Implementation Partners
   - Links to Screener & Annual Report

CRITERIA FOR PROSPECT:
======================
✅ Turnover >= ₹1,000 Crore (FY25)
✅ Net Worth >= ₹500 Crore (FY25)
✅ Net Profit >= ₹5 Crore (FY25)
